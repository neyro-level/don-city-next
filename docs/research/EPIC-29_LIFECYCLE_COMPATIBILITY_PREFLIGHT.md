# EPIC-29 — preflight жизненного цикла и совместимости URL

## Решение

- Канонический URL карточки: `/{категория}/{semantic}-{publicUrlId}/`.
- Активная карточка возвращает `200` и индексируется.
- Архивная карточка возвращает `200` с `noindex,follow`.
- Ошибка категории или semantic при корректном `publicUrlId` получает один `301` на `property.href`.
- Очищенный объект без допустимого целевого пути получает `410`; с валидным явным путём — `308`.
- Неизвестный объект получает `404`.

## Donor URL

Маршрут `/obekty/[slug]` не подключается. В кодовой базе и утверждённом плане нет подтверждённой legacy-карты `slug → publicUrlId` либо списка исходных URL. Включение общего редиректа без такой карты создало бы дубли и риск неверного назначения. До появления подтверждённых данных этот маршрут должен возвращать `404`.

## Проверяемый контракт

`pnpm verify:property-lifecycle-routes` воспроизводимо проверяет `200`, архивный `200/noindex`, `301`, `410`, `308`, `404` и отказ от неподтверждённого donor URL.
